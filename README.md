# Визуализатор зависимостей pip-пакетов — этап 1

Практическая работа №2, вариант №19. Приложение на Go
читает INI-файл, проверяет настройки и выводит их
в формате `ключ=значение`.

## Настройки

Все параметры обязательны и находятся в `[settings]`:

```ini
[settings]
package = requests
repository = https://pypi.org
test_mode = false
```

| Параметр | Назначение |
| --- | --- |
| `package` | Имя пакета |
| `repository` | URL репозитория или путь к файлу |
| `test_mode` | Тестовый режим: `true` или `false` |

В _обычном режиме_ имя содержит латинские буквы, цифры,
`.`, `_`, `-` и начинается и заканчивается буквой
или цифрой. Репозиторий задаётся URL с `http` или `https`.
В _тестовом режиме_ имя содержит только буквы `A–Z`,
а репозиторий задаётся доступным для чтения файлом.
На этапе 1 проверяются настройки и доступность файла;
обращение к серверу и чтение графа не выполняются.

По умолчанию используется `config.ini`.
Флаг `-config` выбирает другой файл.
Относительные пути считаются от рабочего каталога.
Пустые строки и отдельные комментарии с `#` или `;`
пропускаются. Значения указываются без кавычек.
Неизвестные, повторные и пустые параметры запрещены.

## Сборка и тесты

Требуется Go 1.27+. Запускать из корня проекта:

```bash
make build   # собрать bin/pkg-dep-vis
make test    # запустить тесты
make check   # тесты и проверки оформления
```

Для `make check` нужен `golangci-lint` в `PATH`.

## Примеры запуска

```bash
make run ARGS="-config configs/online.ini"
./bin/pkg-dep-vis -config configs/test.ini
```

Вывод для обычного режима:

```text
package=requests
repository=https://pypi.org
test_mode=false
```

Ошибки имени пакета, URL, режима, обязательных
параметров и файлов выводятся в `stderr`.
Код завершения: `0` — успех, `1` — ошибка.
Например, `package=-requests`, `repository=not-a-url`
или `test_mode=yes` приведут к ошибке проверки.

## Функции

| Функция | Назначение |
| --- | --- |
| `main` | Разбор флага и завершение процесса |
| `Run` | Загрузка, вывод и код завершения |
| `LoadConfig` | Открытие, разбор и проверка INI |
| `parseConfig` | Чтение строк и контроль ошибок |
| `parseConfigLine` | Разбор секции или строки |
| `addSetting` | Добавление пары ключ-значение |
| `validateConfig` | Проверка параметров и режима |
| `validateRepositoryURL` | Проверка URL репозитория |
| `validateTestRepository` | Проверка тестового файла |
| `stringConfig` | Формирование вывода настроек |
