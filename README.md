# Визуализатор зависимостей pip-пакетов

Практическая работа №2, вариант №19. Консольное приложение на Go:
получает зависимости пакетов и выводит граф списком смежности.

## Этапы работы

1. **Конфигурация.** Чтение INI-файла, проверка обязательных параметров
   `package`, `repository`, `test_mode` и вывод настроек в формате `ключ=значение`.
   Ошибки параметров и файлов выводятся в `stderr`, код завершения — `1`.
2. **Получение зависимостей.** Загрузка прямых зависимостей через PyPI JSON API
   (`/pypi/<package>/json`, поле `info.requires_dist`) средствами стандартной
   библиотеки Go, без вызова pip.
3. **Построение графа.** Поиск прямых и транзитивных зависимостей алгоритмом BFS
   без рекурсии. Поддерживаются циклы, общие зависимости и пакеты без зависимостей.
   В тестовом режиме граф читается из локального файла, имена пакетов — буквы `A–Z`.

Ограничения версий, extras и условия окружения не вычисляются:
в граф включаются все объявленные зависимости.

## Настройки

По умолчанию используется `config.ini`, другой файл задаётся флагом `-config`.
Все три параметра обязательны:

```ini
[settings]
package = requests
repository = https://pypi.org
test_mode = false
```

`package` — имя пакета; `repository` — URL репозитория, а при
`test_mode = true` — путь к текстовому файлу. Относительные пути считаются
от каталога запуска.

Формат тестового файла (каждый пакет объявляется отдельной строкой):

```text
A: B C
B: D
C: D
D:
```

## Сборка, запуск и проверка

Требуется Go 1.27+. Команды выполняются из корня проекта:

```bash
make build
./bin/pkg-dep-vis -config configs/online.ini
./bin/pkg-dep-vis -config configs/test.ini
make test
```

Пример вывода для `configs/test.ini`:

```text
package=A
repository=configs/test-repository.txt
test_mode=true
A: B, C
B: D
C: D
D:
```

Демонстрация трёх конфигураций: `sh scripts/demo.sh` (нужен доступ к PyPI).
Три локальных примера — транзитивные зависимости, цикл и пакет без зависимостей:
`sh scripts/demo-test.sh`.

## Основные функции

- `LoadConfig` — чтение и проверка конфигурации.
- `LoadDependencies` — получение прямых зависимостей из репозитория.
- `BuildGraph`, `LoadGraph`, `LoadTestGraph` — обход и построение графа.
- `PrintGraph` — вывод списка смежности; `Run` — запуск приложения.

Тесты в `tests/` проверяют конфигурацию, загрузку зависимостей,
построение графа и тестовый режим. Полная проверка: `make check`
(дополнительно требуется `golangci-lint` v2).
